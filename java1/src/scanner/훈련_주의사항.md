## 1. Scanner 기본

`System.out` 을 통해서 출력을 했듯이, `System.in` 을 통해서 사용자의 입력을 받을 수 있습니다. 그런데 `System.in` 을 직접 사용하면 여러 과정을 거쳐야 해서 복잡하고 어렵습니다. 자바는 이런 문제를 해결하기 위해 `Scanner` 라는 클래스를 제공합니다.

```java
// Scanner1
import java.util.Scanner;   // 반드시 필요

public class Scanner1 {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("문자열을 입력하세요:");
        String str = scanner.nextLine();          // 입력을 String으로 가져옵니다.
        System.out.println("입력한 문자열: " + str);

        System.out.print("정수를 입력하세요:");
        int intValue = scanner.nextInt();         // 입력을 int로 가져옵니다.
        System.out.println("입력한 정수: " + intValue);

        System.out.print("실수를 입력하세요:");
        double doubleValue = scanner.nextDouble(); // 입력을 double로 가져옵니다.
        System.out.println("입력한 실수: " + doubleValue);
    }
}
```

| 메서드 | 동작 |
|---|---|
| `nextLine()` | 엔터(`\n`)를 입력할 때까지의 문자를 가져온다 (한 줄 전체) |
| `nextInt()` | 입력을 `int` 형으로 가져온다 |
| `nextDouble()` | 입력을 `double` 형으로 가져온다 |

- `Scanner scanner = new Scanner(System.in);` 은 객체와 클래스를 배워야 정확히 이해할 수 있습니다. 지금은 `Scanner` 의 기능을 사용하기 위해 `new` 를 사용해서 `Scanner` 를 만든다 정도로 이해하면 됩니다.
- `import java.util.Scanner;` 가 없으면 `cannot find symbol` 컴파일 에러가 납니다. (IntelliJ 에서 `Alt + Enter` 로 자동 추가 가능)

## 2. 다른 타입을 입력하면 예외가 발생한다

타입이 다르면 오류가 발생합니다. 예제와 같이 숫자에 문자를 입력하면 오류가 발생합니다.

```
문자열을 입력하세요:hello
입력한 문자열: hello
정수를 입력하세요:만원
Exception in thread "main" java.util.InputMismatchException
	at java.base/java.util.Scanner.throwFor(Scanner.java:939)
	at java.base/java.util.Scanner.next(Scanner.java:1594)
	at java.base/java.util.Scanner.nextInt(Scanner.java:2258)
	at java.base/java.util.Scanner.nextInt(Scanner.java:2212)
	at scanner.Scanner1.main(Scanner1.java:15)
```

- `nextInt()` 에 `1.5`, `abc`, `만원` 등을 입력하면 `InputMismatchException` 이 발생합니다.
- `nextInt()` 에 `int` 범위를 넘는 숫자(`3000000000`)를 입력해도 같은 예외가 발생합니다.
- 반면 `nextDouble()` 에 `10` 을 입력하면 정상적으로 `10.0` 이 됩니다. (자동 형변환과 같은 원리)

> 지금은 올바른 값을 입력한다고 가정하고 넘어갑니다. 예외를 처리하는 방법은 뒤에서 학습합니다.

## 3. `nextInt()` 다음에 `nextLine()` 을 쓰면 입력이 건너뛰어진다 ⚠️

**훈련 파트에서 가장 많이 하는 실수입니다.**

사용자가 `30` 을 입력하고 엔터를 치면 입력 버퍼에는 `30\n` 이 들어갑니다.

- `nextInt()` 는 숫자 `30` 만 가져가고 **`\n`(엔터)은 버퍼에 남겨 둡니다.**
- 그다음 `nextLine()` 은 엔터(`\n`)까지 읽는데, 버퍼에 남은 `\n` 을 바로 만나서 **빈 문자열 `""`** 을 반환합니다.

```java
// X 문제가 되는 코드
while (true) {
    System.out.print("이름을 입력하세요 (종료를 입력하면 종료): ");
    String name = input.nextLine();     // 두 번째 반복부터 "" 이 들어감!
    if (name.equals("종료")) { break; }

    System.out.print("나이를 입력하세요: ");
    int age = input.nextInt();          // "30\n" 에서 30 만 가져감, \n 은 남음
    System.out.println("입력한 이름: " + name + ", 나이: " + age);
}
```

```
이름을 입력하세요 (종료를 입력하면 종료): 자바
나이를 입력하세요: 30
입력한 이름: 자바, 나이: 30
이름을 입력하세요 (종료를 입력하면 종료): 나이를 입력하세요:     ← 이름 입력이 건너뛰어짐!
```

**해결: 숫자 입력 후 `nextLine()` 을 한 번 호출해서 남은 줄바꿈을 버린다.**

```java
// O ScannerWhileEx1
System.out.print("나이를 입력하세요: ");
int age = input.nextInt();
input.nextLine();  // 숫자 입력 후의 줄바꿈 처리
```

```java
// O ScannerWhileEx4 - 옵션(숫자)을 입력받은 뒤 상품명(문자열)을 입력받을 때
int option = input.nextInt();
if (option == 1) {
    input.nextLine();  // 이전에 입력된 개행문자 제거
    System.out.print("상품명을 입력하세요: ");
    String product = input.nextLine();
    ...
}
```

> 정리
> - `nextLine()` → `nextInt()` 순서: 문제 없음 (`ScannerEx1`, `ScannerEx3`)
> - `nextInt()` → `nextInt()` 순서: 문제 없음 (`nextInt()` 는 앞의 공백/줄바꿈을 건너뜀)
> - **`nextInt()` / `nextDouble()` → `nextLine()` 순서: 문제 발생** → 중간에 `nextLine()` 한 번 추가

## 4. `next()` 와 `nextLine()`

```java
// 입력: 홍 길동
String a = scanner.next();      // "홍"     - 공백 전까지만 (한 단어)
String b = scanner.nextLine();  // "홍 길동" - 엔터 전까지 (한 줄 전체)
```

이름처럼 **공백이 들어갈 수 있는 입력**은 `nextLine()` 을 사용하세요.

## 5. `print()` vs `println()`

```java
System.out.print("hello");
System.out.print("world");
//결과: helloworld

System.out.println("hello");
System.out.println("world");
//결과:
//hello
//world
```

- `print()` : 출력하고 다음 라인으로 넘기지 않는다.
- `println()` : 출력하고 다음 라인으로 넘긴다. `print()` 의 마지막에 `\n` 을 추가한 것과 같다.
- 엔터 키를 치면 `\n` 이라는 문자를 남깁니다. 이 문자는 영어로 new line character, 한글로 줄바꿈 문자 또는 개행 문자라고 합니다.

```java
System.out.print("hello\n");  // println("hello") 와 같다
```

> 입력 안내 문구는 `print()` 를 사용하면 **같은 줄에서** 입력을 받을 수 있어 보기 좋습니다.
> ```java
> System.out.print("문자열을 입력하세요:");   // 문자열을 입력하세요:hello
> ```

## 6. 반복해서 입력받기

### 6-1. 문자열 종료 조건은 `.equals()`

```java
// ScannerWhile1
while (true) {
    System.out.print("문자열을 입력하세요(exit: 종료):");
    String str = scanner.nextLine();
    if (str.equals("exit")) {        // O
        System.out.println("프로그램을 종료합니다.");
        break;
    }
    System.out.println("입력한 문자열: " + str);
}
```

```java
if (str == "exit") { }   // X 입력받은 문자열은 == 으로 비교하면 false 가 나옴 → 종료 안 됨
```

> 대소문자도 구분합니다. `"Exit"`, `"EXIT"` 은 `"exit"` 과 다릅니다. (필요하면 `str.equalsIgnoreCase("exit")`)

### 6-2. 종료 값은 누적하기 **전에** 검사

```java
// O ScannerWhile3 - 검사 → 누적
int sum = 0;
while (true) {
    int number = input.nextInt();
    if (number == 0) {
        break;
    }
    sum += number;
}

// X 누적 → 검사: 종료 값이 합계에 포함됨
while (true) {
    int number = input.nextInt();
    sum += number;           // -1 로 종료하는 경우 sum 에 -1 이 더해짐!
    if (number == -1) {
        break;
    }
}
```

`0` 으로 종료할 때는 더해도 티가 나지 않지만, `-1` 로 종료하는 문제(`ScannerWhileEx2`, `ScannerWhileEx3`)에서는 결과가 틀려집니다.

### 6-3. 두 값이 모두 0 일 때 종료 (`ScannerWhile2`)

```java
if (num1 == 0 && num2 == 0) {   // 둘 다 0 이어야 종료
    System.out.println("프로그램 종료");
    break;
}
```

`||` 로 쓰면 둘 중 하나만 0 이어도 종료됩니다. 문제의 조건(**모두**, **하나라도**)을 정확히 읽으세요.

### 6-4. 대입과 비교를 한 번에 - 괄호 필수

```java
// ScannerWhileEx3 - 반복문 예제2
while ((input = scanner.nextInt()) != -1) {
    sum += input;
    count++;
}
```

```java
while ((input = scanner.nextInt()) != -1) //사용자 3입력
while ((input = 3) != -1) //input에 3 대입
while ((input(3)) != -1)  //input의 값 읽기
while (3 != -1)           //등부등식 연산
while (true)              //while문 실행
```

> 주의: 괄호를 빼고 `input = scanner.nextInt() != -1` 로 쓰면, 대입 연산자의 우선순위가 가장 낮아서 `scanner.nextInt() != -1` (boolean) 을 `int` 변수에 넣으려다 **컴파일 에러**가 납니다.

### 6-5. `Scanner` 는 반복문 밖에서 한 번만 생성

```java
// X 반복할 때마다 새로 만듦
while (true) {
    Scanner scanner = new Scanner(System.in);
    ...
}

// O
Scanner scanner = new Scanner(System.in);
while (true) {
    ...
}
```

## 7. 평균 계산

```java
// ScannerWhileEx3
double average = (double) sum / count;
```

- `sum / count` 는 `int / int` 라서 소수점이 버려집니다. `(double) sum / count` 처럼 **한쪽을 `double` 로** 바꿔야 합니다. (`casting/형변환_주의사항.md` 참고)
- `(double) (sum / count)` 는 이미 버려진 뒤에 바꾸므로 틀립니다.

> 주의: 처음부터 `-1` 을 입력하면 `count` 가 `0` 입니다.
> - `sum / count` (int) → `ArithmeticException: / by zero` 로 종료
> - `(double) sum / count` → 예외는 안 나지만 `NaN` 이 출력됨
>
> ```java
> if (count == 0) {
>     System.out.println("입력한 숫자가 없습니다.");
> } else {
>     double average = (double) sum / count;
>     ...
> }
> ```

## 8. 두 변수의 값 교환 (`ChangeVarEx`)

`a` 와 `b` 를 한번에 서로 교환할 수는 없습니다.

```java
// X
a = b;   // a의 값인 10은 사라져 버림 → a, b 둘 다 20
b = a;

// O temp 에 a 의 값을 먼저 보관
temp = a;   // temp = 10
a = b;      // a = 20
b = temp;   // b = 10
```

`a = b` 라고 하기 전에 `a` 의 값을 어딘가에 보관해 두어야 합니다. 여기서는 임시로 사용할 변수인 `temp` 에 보관해 두었습니다.

### 8-1. 교환에 쓰는 `temp` 는 필요한 블록 안에서 선언 (`ScannerEx5`)

```java
if (num1 > num2) {
    int temp = num1;   // 교환할 때만 필요 → 스코프를 if 블록으로 한정
    num1 = num2;
    num2 = temp;
}
```

## 9. 출력 형식 맞추기

### 9-1. 마지막 항목 뒤에 구분자 넣지 않기 (`ScannerEx5`)

```java
// X 2,3,4,5,   ← 마지막에 쉼표가 붙음
for (int i = num1; i <= num2; i++) {
    System.out.print(i + ",");
}

// O 2,3,4,5
for (int i = num1; i <= num2; i++) {
    System.out.print(i);
    if (i != num2) {          // 마지막이 아닐 때만 쉼표
        System.out.print(",");
    }
}
```

### 9-2. 문자열 더하기 안의 계산은 괄호로

```java
System.out.println(n + " x " + i + " = " + n * i);        // O * 는 + 보다 먼저 계산
System.out.println("합계: " + price + quantity);           // X "합계: 10003" (문자열 이어 붙이기)
System.out.println("합계: " + (price * quantity));         // O 의도를 명확하게
```

## 10. 상태 값 관리 (`ScannerWhileEx4`)

### 10-1. 누적 변수는 반복문 밖, 결제 후에는 직접 초기화

```java
int totalCost = 0;                // 반복문 밖에서 선언 → 상품을 여러 개 담을 수 있음
while (true) {
    int option = input.nextInt();
    if (option == 1) {
        ...
        totalCost += price * quantity;
    } else if (option == 2) {
        System.out.println("총 비용: " + totalCost);
        totalCost = 0;            // 결제 후 총 비용 초기화 (다음 사용자를 위해)
    } else if (option == 3) {
        System.out.println("프로그램을 종료합니다.");
        break;
    } else {
        System.out.println("올바른 옵션을 선택해주세요.");  // 잘못된 입력도 처리
    }
}
```

- `totalCost` 를 반복문 **안**에서 선언하면 상품을 입력할 때마다 0 이 되어 누적되지 않습니다.
- 결제 후 `totalCost = 0;` 을 빠뜨리면 다음 사용자에게 이전 금액이 청구됩니다.
- 마지막 `else` 가 없으면 `4` 같은 잘못된 옵션을 입력했을 때 아무 반응 없이 넘어갑니다.

### 10-2. 금액 계산의 오버플로우

`price * quantity` 가 약 20억을 넘으면 `int` 오버플로우로 음수가 될 수 있습니다. 금액이 클 수 있다면 `long` 을 사용하세요.

- [ ] 공백이 있는 문자열은 `nextLine()`
- [ ] 입력 안내는 `print()`, 결과는 `println()`
- [ ] 문자열 종료 조건은 `.equals()`
- [ ] 종료 값 검사 → 누적 순서
- [ ] 평균은 `(double) sum / count`, `count == 0` 확인
- [ ] 값 교환은 `temp` 사용
- [ ] 누적 변수는 반복문 밖, 필요할 때 직접 초기화
- [ ] 잘못된 입력(else)도 처리
