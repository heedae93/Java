## 1. 배열이 필요한 이유

```java
// Array1 - 학생이 늘어날 때마다 변수와 출력 코드를 추가해야 함
int student1 = 90;
int student2 = 80;
...
System.out.println("학생1 점수: " + student1);
System.out.println("학생2 점수: " + student2);
```

- 학생 수가 증가함에 따라 코딩 양이 비례해서 증가하는 문제가 발생합니다.
- 변수의 이름이 다르기 때문에 반복문도 적용할 수 없습니다.

이렇게 **같은 타입의 변수를 반복해서 선언하고 반복해서 사용하는 문제**를 해결하는 것이 바로 배열입니다.

## 2. 배열 변수 선언과 배열 생성은 다르다

```java
int[] students;          //1. 배열 변수 선언
students = new int[5];   //2. 배열 생성
```

### 2-1. 배열 변수 선언

- 일반적인 변수와 차이점은 `int[]` 처럼 타입 다음에 대괄호(`[]`)가 들어간다는 점입니다.
- **배열 변수를 선언한다고해서 아직 사용할 수 있는 배열이 만들어진 것은 아닙니다!**
- `int a` 에는 정수를, `double b` 에는 실수를 담을 수 있듯이, `int[] students` 와 같은 배열 변수에는 **배열**을 담을 수 있습니다. (10, 20 같은 값이 아니라 배열이라는 것을 담을 수 있다)

```java
int[] students;
students[0] = 90;  // X 컴파일 에러: variable students might not have been initialized

int[] arr = null;
arr[0] = 90;       // X 실행 중 NullPointerException
```

### 2-2. 배열 생성

- `new int[5]` 라고 입력하면 총 5개의 `int` 형 변수가 만들어집니다.
- `new` 는 새로 생성한다는 뜻이고, `int[5]` 는 `int` 형 변수 5개라는 뜻입니다.
- 배열을 생성하면 배열의 크기만큼 메모리를 확보합니다. `int` 형을 5개 사용하면 `4byte * 5` → `20byte` 를 확보합니다.

### 2-3. 배열은 자동으로 초기화된다

자바는 배열을 생성할 때 그 내부값을 자동으로 초기화합니다.

| 타입 | 기본값 |
|---|---|
| 숫자 (`int`, `long`, `double` …) | `0` (`0.0`) |
| `boolean` | `false` |
| `String` | `null` (없다는 뜻) |

```java
String[] names = new String[3];
System.out.println(names[0]);            // null
System.out.println(names[0].length());   // X NullPointerException
```

> 지역 변수는 초기화하지 않으면 컴파일 에러지만, **배열의 요소는 자동으로 기본값**이 들어갑니다. (`variable/변수_초기화.md` 참고)

## 3. 인덱스는 0 부터 시작한다

`new int[5]` 와 같이 5개의 요소를 가지는 `int` 형 배열을 만들었다면 인덱스는 `0,1,2,3,4` 가 존재합니다.
**사용 가능한 인덱스의 범위는 `0 ~ (n-1)`** 입니다. 그래서 `students[4]` 가 배열의 마지막 요소입니다.

```java
int[] students = new int[5];
students[5] = 100;   // X
```

```
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 5 out of bounds for length 5
	at array.Array1Ref1.main(Array1Ref1.java:14)
```

- **컴파일 에러가 아니라 실행 중에** 발생하는 예외입니다. 예외가 발생하면 프로그램이 종료됩니다.
- 음수 인덱스(`students[-1]`)도 같은 예외가 발생합니다.

### 3-1. 반복문 조건은 `<`

```java
for (int i = 0; i < students.length; i++)   // O 0 ~ 4
for (int i = 0; i <= students.length; i++)  // X 0 ~ 5 → students[5] 에서 예외
for (int i = 1; i <= students.length; i++)  // X 첫 요소 students[0] 누락 + 마지막에 예외
```

### 3-2. "1번 학생"과 인덱스 0

사람은 1부터 세고 배열은 0부터 셉니다. 출력할 때만 `+ 1` 을 하세요.

```java
for (int i = 0; i < students.length; i++) {
    System.out.println("학생" + (i + 1) + " 점수: " + students[i]);
}
```

> 주의: `"학생" + i + 1` 은 문자열 더하기라서 `"학생01"` 이 됩니다. **괄호 `(i + 1)` 필수!**

### 3-3. 역순 출력 (`ArrayEx3`)

```java
for (int i = numbers.length - 1; i >= 0; i--)   // O 마지막 인덱스는 length - 1
for (int i = numbers.length; i >= 0; i--)       // X numbers[5] 에서 예외
for (int i = numbers.length - 1; i > 0; i--)    // X numbers[0] 누락
```

## 4. 배열 초기화 문법

```java
// 1. 생성 후 하나씩 대입
int[] students = new int[5];
students[0] = 90;

// 2. 생성과 동시에 초기화 (Array1Ref3)
int[] students;
students = new int[]{90, 80, 70, 60, 50};

// 3. 간단한 배열 생성 (Array1Ref4)
int[] students = {90, 80, 70, 60, 50};
```

### 4-1. `{}` 만 쓰는 방법은 선언과 함께일 때만

```java
int[] students;
students = {90, 80, 70, 60, 50};               // X 컴파일 에러
students = new int[]{90, 80, 70, 60, 50};      // O
```

### 4-2. 크기와 초기값을 같이 쓸 수 없다

```java
int[] a = new int[5]{1, 2, 3, 4, 5};  // X 컴파일 에러
int[] b = new int[]{1, 2, 3, 4, 5};   // O 크기는 요소 개수로 자동 결정
```

## 5. `length`

```java
students.length   // 배열의 길이 (5)
```

- 배열의 길이를 제공하는 특별한 기능입니다.
- 이 값은 **조회만 할 수 있습니다. 대입은 할 수 없습니다.**
- 배열의 크기는 **생성 후에 바꿀 수 없습니다.** 더 많은 공간이 필요하면 더 큰 배열을 새로 만들어야 합니다.

```java
students.length = 10;   // X 컴파일 에러
students.length();      // X 배열은 () 없음
"hello".length();       // 문자열은 () 있음 - 헷갈리지 말 것!
```

### 5-1. 숫자 대신 `length` 를 쓰자

```java
// X ArrayEx3, ArrayEx4 - 5 를 여러 곳에 직접 씀
int[] numbers = new int[5];
for (int i = 0; i < 5; i++) { ... }
double average = (double) sum / 5;

// O ArrayEx1Ref - 배열 크기가 바뀌어도 나머지 코드는 그대로
int[] students = {90, 80, 70, 60, 50};
for (int i = 0; i < students.length; i++) { ... }
double average = (double) total / students.length;
```

이제 학생의 점수를 추가해도 `{90, 80, 70, 60, 50}` 의 내용만 변경하면 됩니다. 나머지 코드는 변경하지 않아도 됩니다.

### 5-2. 평균은 `(double)`

```java
double average = (double) total / students.length;   // O 70.0
double average = total / students.length;            // X int / int → 소수점 버림
```

## 6. 배열 변수에는 참조값이 들어 있다

`new int[5]` 로 배열을 생성하면 자바는 메모리 어딘가에 있는 이 배열에 접근할 수 있는 **참조값(주소)** 을 반환합니다.
배열 변수 `int[] students` 는 이 참조값을 보관합니다.

```java
int[] students = new int[5]; //1. 배열 생성
int[] students = x001;       //2. new int[5]의 결과로 x001 참조값 반환
students = x001              //3. 최종 결과

students[0] = 90;            //1. 배열에 값을 대입
x001[0] = 90;                //2. 변수에 있는 참조값을 통해 실제 배열에 접근. 인덱스를 사용해서 해당 위치의 요소에 접근, 값 대입
```

### 6-1. 기본형 vs 참조형

| | 기본형 (Primitive Type) | 참조형 (Reference Type) |
|---|---|---|
| 예 | `int`, `long`, `double`, `boolean` | `int[]`, `String`, 객체, 클래스 |
| 저장하는 것 | 사용할 **값을 직접** 저장 | 데이터에 접근하기 위한 **참조(주소)** 저장 |
| 크기 | 선언과 동시에 정해짐 (`int` 4byte) | **동적으로** 정할 수 있음 (`new int[size]`) |

```java
int size = 10000;   //사용자가 입력한 값을 넣었다고 가정해보자.
new int[size];      //이 코드가 실행되는 시점에 배열의 크기가 정해진다.
```

> 주의: `size` 가 음수면 `NegativeArraySizeException`, `0` 이면 길이 0 인 배열이 만들어집니다. (`numbers[0]` 접근 시 예외)

### 6-2. 배열을 그대로 출력하면 참조값이 나온다

```java
System.out.println(students);  //[I@4617c264 @앞의 [I는 int형 배열을 뜻한다. @뒤에 16진수는 참조값을 뜻한다.
```

내용을 보려면 반복문으로 출력하거나 `Arrays.toString()` 을 사용합니다.

```java
System.out.println(java.util.Arrays.toString(students));  // [90, 80, 70, 60, 50]
```

### 6-3. 배열 변수를 대입하면 **같은 배열**을 가리킨다 (복사가 아님)

```java
int[] a = {1, 2, 3};
int[] b = a;          // 참조값(x001)만 복사 → a 와 b 가 같은 배열을 가리킴
b[0] = 100;
System.out.println(a[0]);  // 100 ← a 도 바뀜!
```

### 6-4. 배열 비교는 `==` 로 하지 않는다

```java
int[] a = {1, 2, 3};
int[] b = {1, 2, 3};
System.out.println(a == b);                          // false (참조값 비교)
System.out.println(java.util.Arrays.equals(a, b));   // true  (내용 비교)
```

> 기본형과 참조형에 대한 자세한 내용은 객체를 설명할 때 다룹니다.

## 9. 2차원 배열

2차원 배열은 행(row)과 열(column)으로 구성됩니다. `arr[행][열]`, `arr[row][column]`

```java
int[][] arr = new int[2][3]; //행(row), 열(column)
arr[1][2] = 6;               //1행, 2열
```

### 9-1. 행 길이와 열 길이 (`ArrayDi3`)

```java
int[][] arr = {
        {1, 2, 3},
        {4, 5, 6}
};
for (int row = 0; row < arr.length; row++) {                   // arr.length → 행의 길이 (2)
    for (int column = 0; column < arr[row].length; column++) { // arr[row].length → 열의 길이 (3)
        System.out.print(arr[row][column] + " ");
    }
    System.out.println(); //한 행이 끝나면 라인을 변경한다.
}
```

- `arr.length` 는 **행의 길이**입니다. `{{},{}}` 를 생각해보면 `arr` 배열은 `{}`, `{}` 2개의 배열 요소를 가집니다.
- `arr[row].length` 는 **열의 길이**입니다. `arr[0]` 은 `{1,2,3}` 배열을 뜻합니다.

```java
// X 행과 열 길이를 바꿔 씀
for (int row = 0; row < arr[0].length; row++)     // 3 행까지 돌다가 arr[2] 에서 예외
    for (int column = 0; column < arr.length; column++)  // 2 열까지만 → 3번째 열 누락
```

### 9-2. 숫자 대신 `length` 사용

```java
for (int row = 0; row < 2; row++)              // X 배열 크기가 바뀌면 같이 고쳐야 함
for (int row = 0; row < arr.length; row++)     // O
```

`new int[2][3]` 을 `new int[4][5]` 처럼 다른 숫자로 변경해도 나머지 코드를 변경하지 않고 잘 동작합니다. (`ArrayDi4`)

### 9-3. 초기화는 줄을 맞춰서

```java
int[][] arr = {{1, 2, 3},{4, 5, 6}};   // 행열이 잘 안느껴짐

int[][] arr = {                        // 행과 열이 명확
        {1, 2, 3},
        {4, 5, 6}
};
```

### 9-4. 증감 연산자로 값 넣기 (`ArrayDi4`)

```java
int i = 1;
arr[row][column] = i++;   // 후위 증감: 값을 먼저 대입한 다음에 증가
```

`++i` 로 쓰면 2부터 들어갑니다.

> 참고: 행마다 열의 길이가 다를 수도 있습니다. 그래서 열 길이는 `arr[0].length` 가 아니라 **`arr[row].length`** 로 쓰는 것이 안전합니다.
> ```java
> int[][] jagged = { {1}, {2, 3}, {4, 5, 6} };
> ```

## 10. 향상된 for 문 (for-each)

```java
for (변수 : 배열 또는 컬렉션) {
    // 배열 또는 컬렉션의 요소를 순회하면서 수행할 작업
}
```

```java
int[] numbers = {1, 2, 3, 4, 5};
for (int number : numbers) {
    System.out.println(number);
}
```

- 배열의 인덱스를 사용하지 않고, 종료 조건을 주지 않아도 됩니다. 단순히 해당 배열을 처음부터 끝까지 탐색합니다.
- `:` 의 오른쪽에 탐색할 배열, 왼쪽에 반복할 때마다 찾은 값을 저장할 변수를 선언합니다.
- 인덱스 실수(`<=` 등)를 할 일이 없어서 코드가 간결하고 가독성이 좋습니다.

### 10-1. 인덱스가 필요하면 일반 for 문

향상된 for 문에는 증가하는 인덱스 값이 감추어져 있습니다. 따라서 `int i` 와 같은 증가하는 인덱스 값을 직접 사용해야 하는 경우에는 향상된 for 문을 사용할 수 없습니다.

```java
//for-each문을 사용할 수 없는 경우, 증가하는 index 값 필요
for (int i = 0; i < numbers.length; ++i) {
    System.out.println("number" + i + "번의 결과는: " + numbers[i]);
}
```

억지스럽게 향상된 for 문 안에서 `i` 를 따로 증가시킬 수도 있지만, 이런 경우 일반 for 문을 사용하는 것이 더 좋습니다.

인덱스가 필요한 대표적인 경우

- 몇 번째 요소인지 출력할 때
- 마지막 요소 뒤에 쉼표를 빼야 할 때
- 역순으로 순회할 때
- 배열에 **값을 넣을 때**

### 10-2. 향상된 for 문의 변수를 바꿔도 배열은 그대로

```java
int[] numbers = {1, 2, 3};
for (int number : numbers) {
    number = number * 10;   // 복사된 값만 바뀜
}
System.out.println(numbers[0]);  // 1 (그대로)

for (int i = 0; i < numbers.length; i++) {
    numbers[i] = numbers[i] * 10;   // O 배열을 바꾸려면 인덱스로
}
```

## 11. 저장 개수와 배열 크기를 구분하자 (`ProductAdminEx`)

배열 크기는 고정이므로, 최대 크기로 만들어 두고 **실제로 저장한 개수**를 따로 관리합니다.

```java
int maxProducts = 10;
String[] productNames = new String[maxProducts];
int[] productPrices = new int[maxProducts];
int productCount = 0;   // 현재 등록된 상품의 개수
```

### 11-1. 저장하기 전에 공간 확인

```java
if (productCount >= maxProducts) {
    System.out.println("더 이상 상품을 등록할 수 없습니다.");
    continue;
}
productNames[productCount] = scanner.nextLine();   // 다음 빈 칸에 저장
productPrices[productCount] = scanner.nextInt();
productCount++;                                    // 저장 후 개수 증가
```

- 공간 확인을 빼면 11번째 상품에서 `ArrayIndexOutOfBoundsException` 이 발생합니다.
- `productCount++` 를 빼면 계속 0번 칸에 덮어씁니다.

### 11-2. 출력은 `length` 가 아니라 `productCount` 까지

```java
for (int i = 0; i < productCount; i++)          // O 등록한 상품만
for (int i = 0; i < productNames.length; i++)   // X 빈 칸은 "null: 0원" 으로 출력됨
```

### 11-3. 등록된 것이 없을 때도 처리

```java
if (productCount == 0) {
    System.out.println("등록된 상품이 없습니다.");
    continue;
}
```

> 참고: 메뉴 번호를 `nextInt()` 로 받은 뒤 상품 이름을 `nextLine()` 으로 받으므로, 중간에 `scanner.nextLine();` 으로 줄바꿈을 제거해야 합니다. (`scanner/훈련_주의사항.md` 참고)

## 12. 정리 체크리스트

- [ ] 배열 변수 선언 후 `new` 로 생성했는가?
- [ ] 인덱스는 `0 ~ length - 1`, 반복 조건은 `i < arr.length`
- [ ] `{}` 간단 초기화는 선언과 같은 줄에서만
- [ ] 배열 크기는 고정, `length` 는 조회만 가능 (괄호 없음)
- [ ] 숫자 대신 `length` 사용
- [ ] `String` 배열의 빈 칸은 `null`
- [ ] 배열 변수에는 참조값 → 출력하면 `[I@...`, 대입하면 같은 배열 공유, 비교는 `Arrays.equals()`
- [ ] 2차원 배열: `arr.length` 는 행, `arr[row].length` 는 열
- [ ] 인덱스가 필요하거나 값을 바꿀 때는 일반 for 문, 단순 순회는 향상된 for 문
- [ ] 최댓값/최솟값은 첫 요소로 시작
- [ ] 저장 개수(`count`)와 배열 크기(`length`)를 구분
