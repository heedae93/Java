# 변수 타입 정리

> 참고 자료: `java1/pdfs/2. 변수.pdf` - "변수 타입1", "변수 타입2", "변수 타입 정리"
> 예제 코드: `Var7.java`, `Var8.java`, `ex/VarEx3.java`

## 한눈에 보기

| 분류 | 타입 | 크기 | 표현 범위 / 값 | 리터럴 예시 | 실무 사용 |
|---|---|---|---|---|---|
| 정수 | `byte` | 1byte | -128 ~ 127 | `127` | 파일 전송·복사 시 |
| 정수 | `short` | 2byte | -32,768 ~ 32,767 | `32767` | 거의 안 씀 |
| 정수 | `int` | 4byte | -2,147,483,648 ~ 2,147,483,647 (약 20억) | `100` | **기본** |
| 정수 | `long` | 8byte | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 | `10000000000L` | 20억 넘을 때 |
| 실수 | `float` | 4byte | 대략 -3.4E38 ~ 3.4E38, 약 7자리 정밀도 | `10.0f` | 거의 안 씀 |
| 실수 | `double` | 8byte | 대략 -1.7E308 ~ 1.7E308, 약 15자리 정밀도 | `10.5` | **기본** |
| 불리언 | `boolean` | 1byte | `true`, `false` | `true` | 자주 씀 (조건문) |
| 문자 | `char` | 2byte | 문자 하나 | `'A'`, `'가'` | 거의 안 씀 |
| 문자열 | `String` | 문자 길이에 따라 동적 | 문자열 | `"Hello Java"` | **기본** |

> 핵심: 실무에서는 **`int`, `long`, `double`, `boolean`, `String`** 이 다섯 개면 충분합니다. 파일을 다룰 때만 `byte`를 씁니다.

## 1. 변수 타입이란?

변수는 **다루는 데이터의 종류**에 따라 다양한 형식이 있습니다.
이 형식을 영어로 **타입(type)**, 우리말로 **형식** 또는 **형**이라고 합니다.
`int 타입`, `int 형식`, `int 형` 모두 같은 말입니다.

```java
int a = 100;             //정수
double b = 10.5;         //실수
boolean c = true;        //불리언(boolean) true, false 입력 가능
char d = 'A';            //문자 하나
String e = "Hello Java"; //문자열, 문자열을 다루기 위한 특별한 타입
```

**실행 결과** (`Var7`)
```
100
10.5
true
A
Hello Java
```

### 1-1. 기본 타입 5가지

- `int` : 정수를 다룹니다. 예) `1`, `100`, `1000`
- `double` : 실수를 다룹니다. 예) `0.2`, `1.5`, `100.121`
- `boolean` : 불리언 타입. `true`, `false` 값만 사용할 수 있습니다. 주로 참과 거짓을 판단하는 곳에서 사용합니다.
- `char` : 문자 **하나**를 다룰 때 사용합니다. **작은따옴표(`'`)** 로 감싸야 합니다. 예) `'A'`, `'가'`
- `String` : 문자열을 다룹니다. **큰따옴표(`"`)** 를 사용해야 합니다. 예) `"hello java"`

> 참고: `String`은 첫 글자가 **대문자**로 시작하는 특별한 타입입니다. 자세한 내용은 클래스를 배운 뒤에 이해할 수 있습니다. 지금은 문자열을 다루는 특별한 타입이라고 이해하면 됩니다.

### 1-2. 자신의 타입에 맞는 데이터를 사용해야 한다

각 변수는 지정한 타입에 맞는 값을 사용해야 합니다. 타입이 맞지 않으면 **컴파일 에러**가 발생합니다.

```java
int a = "백원"; // X 정수 타입에 문자열
int a = "100";  // X 정수 타입에 문자열 (숫자 100이 아니라 문자열 "100")
int a = 100;    // O 정수 타입에 정수 100
```

> `"100"`은 큰따옴표로 감싸져 있으므로 숫자가 아니라 **문자열**입니다.

### 1-3. `char` vs `String`

| | `char` | `String` |
|---|---|---|
| 담는 값 | 문자 **하나** | 문자 **여러 개** (0개, 1개도 가능) |
| 따옴표 | 작은따옴표 `'A'` | 큰따옴표 `"A"`, `"Hello"` |
| 빈 값 | `''` 불가 (컴파일 에러) | `""` 가능 |

```java
char c1 = 'A';      // O
char c2 = "A";      // X 컴파일 에러: 큰따옴표는 String
char c3 = 'AB';     // X 컴파일 에러: 문자 하나만 가능
String s1 = "A";    // O 문자 하나도 String으로 표현 가능
String s2 = "";     // O 빈 문자열
```

## 2. 리터럴 (literal)

코드에서 개발자가 **직접 적은 고정된 값**을 프로그래밍 용어로 **리터럴(literal)** 이라고 합니다.

```java
int a = 100;             //정수 리터럴
double b = 10.5;         //실수 리터럴
boolean c = true;        //불리언 리터럴
char d = 'A';            //문자 하나 리터럴
String e = "Hello Java"; //문자열 리터럴
```

- **변수**의 값은 바뀔 수 있습니다.
- **리터럴**은 개발자가 직접 입력한 고정된 값이므로, 리터럴 자체는 변하지 않습니다.

> 참고: 리터럴(literal)이라는 단어의 어원은 **문자 또는 글자**를 의미합니다.

## 3. 숫자 타입 자세히

```java
//정수
byte b = 127;          //-128 ~ 127
short s = 32767;       // -32,768 ~ 32,767
int i = 2147483647;    //-2,147,483,648 ~ 2,147,483,647 (약 20억)

//-9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807
long l = 9223372036854775807L;

//실수
float f = 10.0f;
double d = 10.0;
```

### 3-1. 메모리를 많이 쓸수록 큰 숫자를 표현한다

- 메모리를 **적게** 사용하면 **작은** 숫자를 표현할 수 있습니다.
- 메모리를 **많이** 사용하면 **큰** 숫자를 표현할 수 있습니다.
- 변수를 선언하면 표현 범위에 따라 메모리 공간을 차지합니다. 그래서 필요에 맞도록 다양한 타입을 제공합니다.

### 3-2. 정수형

| 타입 | 크기 | 범위 |
|---|---|---|
| `byte` | 1byte (2⁸) | -128 ~ 127 |
| `short` | 2byte (2¹⁶) | -32,768 ~ 32,767 |
| `int` | 4byte (2³²) | -2,147,483,648 ~ 2,147,483,647 (약 20억) |
| `long` | 8byte (2⁶⁴) | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 |

> 범위가 왜 이렇게 될까? 예를 들어 `byte`는 8비트이므로 2⁸ = 256가지 값을 표현합니다.
> 음수 128개(-128 ~ -1) + `0` + 양수 127개(1 ~ 127) = 256개. `0`이 양수 쪽 자리를 하나 쓰기 때문에 양수 최댓값이 하나 작습니다.

### 3-3. 실수형

| 타입 | 크기 | 범위 | 정밀도 |
|---|---|---|---|
| `float` | 4byte (2³²) | 대략 -3.4E38 ~ 3.4E38 | 약 7자리 |
| `double` | 8byte (2⁶⁴) | 대략 -1.7E308 ~ 1.7E308 | 약 15자리 |

> `E38`은 10³⁸을 의미합니다. 즉 3.4E38 = 3.4 × 10³⁸ 입니다.

### 3-4. 기타

| 타입 | 크기 | 값 |
|---|---|---|
| `boolean` | 1byte | `true`, `false` |
| `char` | 2byte | 문자 하나 |
| `String` | 문자 길이에 따라 동적으로 달라짐 | 문자열 (특별한 타입, 뒤에서 학습) |

## 4. 리터럴 타입 지정 (`L`, `f`)

### 4-1. 정수 리터럴은 기본이 `int`

정수 리터럴은 기본으로 `int`를 사용합니다. 따라서 `int` 범위(약 20억)까지만 표현할 수 있습니다.
숫자가 `int` 범위를 넘어가면 **`L`을 붙여서** 정수 리터럴을 `long`으로 변경해야 합니다.

```java
long a = 10000000000;   // X 컴파일 에러: integer number too large
long b = 10000000000L;  // O long 리터럴
long c = 100;           // O int 범위 안의 값은 L 없이도 long 변수에 넣을 수 있음
```

> 대문자 `L`, 소문자 `l` 모두 가능하지만, 소문자 `l`은 숫자 `1`과 착각할 수 있어서 **대문자 `L`을 권장**합니다.
> 예) `10l` vs `10L` → `10l`은 `101`처럼 보입니다.

> 주의: `long` 변수에 넣는다고 리터럴이 `long`이 되는 것이 아닙니다. **리터럴 자체의 타입**은 `L`이 붙어야 `long`입니다. 그래서 `long a = 10000000000;`은 오른쪽 리터럴이 `int` 범위를 넘으므로 에러가 납니다.

### 4-2. 실수 리터럴은 기본이 `double`

실수 리터럴은 기본이 `double`형입니다. `float`형을 사용하려면 **`f`를 붙여서** `float`형으로 지정해야 합니다.

```java
float f1 = 10.0;   // X 컴파일 에러: double 값을 float에 넣을 수 없음 (possible lossy conversion)
float f2 = 10.0f;  // O float 리터럴 (대문자 F도 가능)
double d = 10.0;   // O 기본이 double
```

### 4-3. 문제 3 예제 (`VarEx3`)

```java
long longVar = 10000000000L; // 100억 → int 범위를 넘으므로 L 필수
System.out.println(longVar);

boolean booleanVar = true;
System.out.println(booleanVar);
```

**실행 결과**
```
10000000000
true
```

## 5. 실무에서는 어떤 타입을 쓸까?

### 5-1. 실무에서 거의 사용하지 않는 타입

- **`byte`** : 표현 길이가 너무 작습니다. 또 자바는 기본으로 4byte(`int`)를 효율적으로 계산하도록 설계되어 있습니다. `int`를 사용합시다.
  - `byte` 타입을 직접 선언하고 숫자 값을 넣어서 계산하는 일은 거의 없습니다.
  - 대신 파일은 바이트 단위로 다루기 때문에 **파일 전송, 파일 복사** 등에 주로 사용됩니다.
- **`short`** : 표현 길이가 너무 작습니다. 자바는 기본으로 `int`를 효율적으로 계산하도록 설계되어 있습니다. `int`를 사용합시다.
- **`float`** : 표현 길이와 정밀도가 낮습니다. 실수형은 `double`을 사용합시다.
- **`char`** : 문자 하나를 표현하는 일은 거의 없습니다. 문자 하나도 문자열로 표현할 수 있습니다.
  - 예) `String a = "b"` 와 같이 사용하면 됩니다.

> 참고: 메모리 용량은 매우 저렴합니다. 따라서 메모리 용량을 약간 절약하기보다는 **개발 속도나 효율에 초점**을 맞추는 것이 더 효과적입니다.

### 5-2. 자주 사용하는 타입

| 분류 | 타입 | 설명 |
|---|---|---|
| 정수 | `int`, `long` | 자바는 정수에 기본으로 `int`를 사용합니다. 20억이 넘을 것 같으면 `long`을 씁니다. |
| 정수 (파일) | `byte` | 파일을 다룰 때 사용합니다. |
| 실수 | `double` | 실수는 고민하지 말고 `double`을 쓰면 됩니다. |
| 불린형 | `boolean` | `true`, `false` 참·거짓을 표현합니다. 이후 조건문에서 자주 사용됩니다. |
| 문자열 | `String` | 문자를 다룰 때는 문자 하나든 문자열이든 모두 `String`을 사용하는 것이 편리합니다. |

자주 사용하는 타입을 제외하고 실무에서 나머지를 사용하는 경우는 거의 없습니다. 그나마 파일 전송 시에 `byte`를 사용하는 정도입니다.
따라서 **자주 사용하는 타입만 이해하고, 나머지는 이런 것이 있구나 하고 넘어가도 충분합니다.**

## 6. 자주 하는 실수

```java
int a = 3000000000;     // X int 범위(약 20억) 초과 → long + L 사용
long b = 3000000000L;   // O

float f = 1.5;          // X 실수 리터럴은 double → 1.5f
double d = 1.5;         // O

char c = "A";           // X char는 작은따옴표
String s = 'A';         // X String은 큰따옴표

boolean flag = "true";  // X 문자열 "true"는 boolean이 아님
boolean flag2 = 1;      // X 자바의 boolean은 숫자(0, 1)로 표현할 수 없음
boolean flag3 = true;   // O

string name = "kim";    // X 소문자 string 은 없는 타입 → String
```

## 7. 정리

1. 변수는 다루는 데이터 종류에 따라 **타입(형식, 형)** 이 있고, 타입에 맞는 값만 넣을 수 있습니다.
2. 코드에 직접 적은 고정된 값을 **리터럴**이라고 합니다.
3. 타입마다 차지하는 **메모리 크기와 표현 범위**가 다릅니다.
4. 정수 리터럴은 기본 `int` → 범위를 넘으면 **`L`**, 실수 리터럴은 기본 `double` → `float`이면 **`f`**.
5. 실무에서는 **`int`, `long`, `double`, `boolean`, `String`** 을 주로 사용합니다. (파일은 `byte`)
