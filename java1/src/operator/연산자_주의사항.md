## 1. 정수끼리 나누면 소수점이 버려진다

자바에서 **같은 `int`형끼리 계산하면 결과도 `int`형**입니다. `int`는 정수이기 때문에 소수점 이하를 포함할 수 없습니다.

```java
int a = 5;
int b = 2;
int div = a / b;
System.out.println("a / b = " + div); // a / b = 2  (2.5 아님!)
```

평균을 구할 때 특히 주의해야 합니다. (`OperationEx1`)

```java
int sum = 10 + 20 + 30;   // 60
int average = sum / 3;    // 20 - int끼리의 나눗셈은 소수점 이하를 버림
```

소수점까지 필요하면 `double`을 사용합니다. (`OperationEx2`)

```java
double sum = 1.5 + 2.5 + 3.5; // 7.5
double avg = sum / 3;         // 2.5
```

> 주의: 결과를 `double` 변수에 담는다고 해결되지 않습니다. **계산 자체가 `int`끼리** 이뤄지면 이미 소수점이 버려진 뒤입니다.
> ```java
> double r = 5 / 2;   // 2.0  (int 계산 결과 2를 double로 바꿨을 뿐)
> double r2 = 5 / 2.0; // 2.5  (한쪽이 double이면 double로 계산)
> ```
> 자세한 내용과 해결 방안은 `6. 스코프, 형변환`에서 다룹니다.

## 2. 0으로 나누면 프로그램이 종료된다

숫자는 0으로 나눌 수 없습니다. (수학에서도 허용하지 않음)

```java
int a = 5;
int b = 0;
System.out.println(a / b);
```

```
Exception in thread "main" java.lang.ArithmeticException: / by zero
```

- 이것은 **컴파일 에러가 아니라 실행 중 발생하는 예외**입니다. 컴파일은 정상적으로 됩니다.
- 예외가 발생하면 **그 이후 코드는 실행되지 않고 프로그램이 종료**됩니다.
- 나머지 연산 `a % 0` 도 같은 예외가 발생합니다.

> 참고: 실수(`double`)를 0으로 나누면 예외가 나지 않고 `Infinity` 또는 `NaN`이 나옵니다. 에러 없이 이상한 값이 나오므로 오히려 더 찾기 어렵습니다.
> ```java
> System.out.println(5.0 / 0); // Infinity
> System.out.println(0.0 / 0); // NaN
> ```

## 3. 나머지 연산자 `%`

`5 / 2`는 몫이 2, 나머지가 1입니다. 따라서 `5 % 2`의 결과는 `1`입니다.
나머지 연산자는 실무와 알고리즘 모두 종종 사용되므로 잘 기억해 둡시다.

```java
System.out.println(5 % 2);  // 1
System.out.println(10 % 2); // 0 → 짝수 판별에 사용
System.out.println(7 % 3);  // 1
```

> 주의: 음수의 나머지는 **왼쪽 피연산자의 부호**를 따릅니다.
> ```java
> System.out.println(-7 % 3); // -1  (2가 아님)
> System.out.println(7 % -3); // 1
> ```
> 그래서 홀수 판별을 `n % 2 == 1` 로 하면 음수 홀수(`-3 % 2 == -1`)를 놓칩니다. **`n % 2 != 0`** 으로 쓰는 것이 안전합니다.

## 4. 문자열 더하기

자바는 문자열에도 `+` 연산자를 사용할 수 있습니다. **문자열에 다른 타입을 더하면 상대 타입을 문자열로 변경**합니다.

```java
"a + b = " + 10      // "a + b = " + "10" → "a + b = 10"
```

### 4-1. 왼쪽부터 순서대로 계산된다

`+` 는 왼쪽에서 오른쪽으로 하나씩 계산합니다. **문자열을 만난 이후부터는 전부 문자열 더하기**가 됩니다.

```java
System.out.println("결과: " + 1 + 2);   // 결과: 12   ("결과: 1" + 2)
System.out.println(1 + 2 + " 결과");    // 3 결과     (3 + " 결과")
System.out.println("결과: " + (1 + 2)); // 결과: 3    괄호가 먼저 계산
```

출력문 안에서 숫자를 계산할 때는 **괄호로 감싸 주세요.**

### 4-2. `-`, `*`, `/` 는 문자열에 쓸 수 없다

```java
String s = "10" - 5;   // X 컴파일 에러
String t = "10" + 5;   // O "105"  (15가 아님!)
```

## 5. 연산자 우선순위

```java
int sum1 = 1 + 2 * 3;   // 1 + (2 * 3) = 7
int sum2 = (1 + 2) * 3; // 9
```

우선순위 (높은 것 → 낮은 것)

1. 괄호 `()`
2. 단항 연산자 (`++`, `--`, `!`, `~`, `new`, `(type)`)
3. 산술 연산자 (`*`, `/`, `%` 우선, 그 다음에 `+`, `-`)
4. Shift 연산자 (`<<`, `>>`, `>>>`)
5. 비교 연산자 (`<`, `<=`, `>`, `>=`, `instanceof`)
6. 등식 연산자 (`==`, `!=`)
7. 비트 연산자 (`&`, `^`, `|`)
8. 논리 연산자 (`&&`, `||`)
9. 삼항 연산자 (`? :`)
10. 대입 연산자 (`=`, `+=`, `-=`, `*=`, `/=`, `%=` 등)

### 외울 필요 없다. 딱 2가지만 기억하자

1. **상식선에서 생각하자** - `*`가 `+`보다 먼저, 대입(`=`)은 항상 마지막.
2. **애매하면 괄호 `()`를 사용하자**

```java
int sum3 = 2 * 2 + 3 * 3;      // 13 - 우선순위를 잠깐 생각해야 함
int sum4 = (2 * 2) + (3 * 3);  // 13 - 바로 이해됨
((2 * 2) + (3 * 3)) / (3 + 2)  // 복잡하면 괄호로 명시
```

> 개발에서 가장 중요한 것은 **단순함과 명확함**입니다. 코드를 몇 줄 줄여서 모호하게 만드는 것보다, 명확하고 단순한 코드가 유지보수하기 좋습니다.

> 주의: `&&` 가 `||` 보다 우선순위가 높습니다. 섞어서 쓸 때는 반드시 괄호를 쓰세요.
> ```java
> a || b && c   // a || (b && c) 로 계산됨
> ```

## 6. 증감 연산자 - 전위(`++a`)와 후위(`a++`)

`++a`, `a++` 모두 `a = a + 1` 입니다. 차이는 **증가가 일어나는 시점**입니다.

| | 전위 `++a` | 후위 `a++` |
|---|---|---|
| 순서 | **증가 먼저**, 그 다음 다른 연산 | **다른 연산 먼저**, 그 다음 증가 |
| `a = 1; b = ++a;` | `a = 2, b = 2` | |
| `a = 1; b = a++;` | | `a = 2, b = 1` |

```java
int a = 1;
int b = ++a; // a = a + 1 (a=2) → b = a (b=2)

a = 1;
b = a++;     // b = a (b=1) → a = a + 1 (a=2)
```

**혼자 쓰면 차이가 없습니다.** 다른 연산이 없기 때문에 본인의 값만 증가합니다.

```java
++a;
a++; // 둘 다 결과 같음
```

> 권장: 헷갈리는 것을 피하려면 **증감 연산자는 단독으로 한 줄에** 쓰세요.
> ```java
> int c = a++ + ++a;  // X 무슨 값인지 바로 알기 어려움
> ```

## 7. `=` 와 `==` 는 다르다

| 연산자 | 이름 | 의미 |
|---|---|---|
| `=` | 대입 연산자 | 오른쪽 값을 왼쪽 변수에 **저장** |
| `==` | 비교 연산자 | 두 값이 **같은지 확인** → `true` / `false` |

```java
int a = 2, b = 3;
System.out.println(a == b); // false
boolean result = a == b;    // 비교 결과 false 를 result 에 대입
```

> 주의: 같지 않음은 `!=` 입니다. (`!`는 반대라는 뜻) `=!`, `<>` 가 아닙니다.
> 주의: `>=`, `<=` 의 순서를 바꿔 `=>`, `=<` 로 쓰면 컴파일 에러입니다.

## 8. 문자열 비교는 `==` 가 아니라 `.equals()`

문자열이 같은지 비교할 때는 `==` 이 아니라 **`.equals()` 메서드**를 사용해야 합니다.
`==` 을 사용하면 성공할 때도 있지만 실패할 때도 있습니다. (자세한 이유는 별도 강의에서 다룸)

```java
String str1 = "문자열1";
String str2 = "문자열2";

boolean result1 = "hello".equals("hello"); // true  - 리터럴 비교
boolean result2 = str1.equals("문자열1");   // true  - 문자열 변수, 리터럴 비교
boolean result3 = str1.equals(str2);       // false - 문자열 변수 비교
```

> 미리 맛보기: `==` 은 **같은 객체인지**(참조)를 비교하고, `.equals()` 는 **내용이 같은지**를 비교합니다.
> ```java
> String s1 = "hello";
> String s2 = new String("hello");
> System.out.println(s1 == s2);      // false (내용은 같지만 다른 객체)
> System.out.println(s1.equals(s2)); // true
> ```

## 9. 논리 연산자

| 연산자 | 의미 | 결과 |
|---|---|---|
| `&&` (AND) | 그리고 | 둘 다 참이어야 `true`, 하나라도 거짓이면 `false` |
| `\|\|` (OR) | 또는 | 하나라도 참이면 `true`, 둘 다 거짓이면 `false` |
| `!` (NOT) | 부정 | `true` ↔ `false` 반대로 |

### 9-1. 범위 비교는 수학처럼 쓸 수 없다

```java
int a = 15;
boolean r1 = 10 < a < 20;           // X 컴파일 에러: (10 < a)는 boolean → boolean < 20 불가
boolean r2 = a > 10 && a < 20;      // O
boolean r3 = 10 < a && a < 20;      // O 범위를 나타낼 때 더 읽기 좋음
```

(`OperationEx3`) 80점 이상 100점 이하:

```java
boolean result = score >= 80 && score <= 100;
```

### 9-2. 단축 평가 (short-circuit)

`&&`, `||` 는 **왼쪽만 보고 결과가 확정되면 오른쪽을 계산하지 않습니다.**

- `false && ???` → 무조건 `false` → 오른쪽 실행 안 함
- `true || ???` → 무조건 `true` → 오른쪽 실행 안 함

```java
int x = 0;
boolean r = (x != 0) && (10 / x > 1); // 왼쪽이 false → 오른쪽 실행 안 함 → 0으로 나누기 예외 없음
```

> 주의: 그래서 오른쪽에 `a++` 같은 값 변경 코드를 넣으면, 실행될 때도 안 될 때도 있어 버그가 생깁니다.

## 10. 대입 연산자 / 축약(복합) 대입 연산자

`+=`, `-=`, `*=`, `/=`, `%=` 는 연산과 대입을 한 번에 처리합니다.

```java
int a = 5;  // 5
a += 3;     // 8  (5 + 3):  a = a + 3
a -= 2;     // 6  (8 - 2):  a = a - 2
a *= 4;     // 24 (6 * 4):  a = a * 4
a /= 3;     // 8  (24 / 3): a = a / 3
a %= 5;     // 3  (8 % 5):  a = a % 5
```

> 주의: 대입 연산자는 **우선순위가 가장 낮아서 항상 마지막**에 처리됩니다.
> `int sum = 1 + 2` → `1 + 2` 를 먼저 계산 → `sum = 3`

> 주의: `=+` 는 `+=` 가 아닙니다. 컴파일 에러도 나지 않아서 더 위험합니다.
> ```java
> a =+ 3; // a = (+3) → a 는 그냥 3이 됨
> a += 3; // a = a + 3
> ```

> 참고: 축약 대입 연산자는 **자동으로 형변환**을 합니다.
> ```java
> int i = 10;
> i = i + 1.5;  // X 컴파일 에러: double 결과를 int에 넣을 수 없음
> i += 1.5;     // O i = (int)(i + 1.5) → 11 (소수점 버려짐)
> ```

## 11. 정리

자주 사용하는 연산자

- 산술 연산자: `+`, `-`, `*`, `/`, `%` (나머지)
- 증가 및 감소 연산자: `++`, `--`
- 비교 연산자: `==`, `!=`, `>`, `<`, `>=`, `<=`
- 논리 연산자: `&&` (AND), `||` (OR), `!` (NOT)
- 대입 연산자: `=`, `+=`, `-=`, `*=`, `/=`, `%=`

뒤에서 학습: 삼항 연산자 `? :`, `instanceof`, `new`, `[]`, `.`, `()`
비트 연산자(`&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`)는 실무에서 거의 사용할 일이 없으므로 필요할 때 찾아보자.

### 꼭 기억할 체크리스트

- [ ] `int / int` 는 소수점이 버려진다 → 필요하면 `double`
- [ ] 0으로 나누면 `ArithmeticException` 으로 프로그램 종료
- [ ] 문자열 `+` 는 왼쪽부터 → 숫자 계산은 괄호로
- [ ] 우선순위는 외우지 말고 괄호로 명확하게
- [ ] `++a` 는 증가 먼저, `a++` 는 증가 나중 → 단독으로 쓰자
- [ ] 비교는 `==`, 대입은 `=`
- [ ] 문자열 비교는 `.equals()`
- [ ] 범위 비교는 `a > 10 && a < 20`
