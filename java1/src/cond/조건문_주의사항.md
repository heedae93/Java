# 조건문 주의사항 정리

> 참고 자료: `java1/pdfs/4. 조건문.pdf`
> 예제 코드: `If1~6`, `Switch1~4`, `CondOp1~2`, `ex/ScoreEx`, `ex/DistanceEx`, `ex/ExchangeRateEx`, `ex/GradeSwitchEx`, `ex/CondOpEx`, `ex/EvenOddEx`

## 한눈에 보기

| # | 주의사항 | 잘못 쓰면 |
|---|---|---|
| 1 | 연관된 조건은 `else if` 로 묶는다 | 불필요한 조건 검사, 중복 체크 |
| 2 | 독립된 조건은 `if` 를 각각 쓴다 | 첫 번째 조건만 실행되고 나머지 누락 (할인 누락) |
| 3 | `else if` 는 **조건 순서**가 중요 | 넓은 조건이 앞에 있으면 아래 조건은 절대 실행 안 됨 |
| 4 | 범위 경계값(`<`, `<=`)을 확인 | 경계값에서 엉뚱한 결과 / 아무것도 실행 안 됨 |
| 5 | `{}` 중괄호는 생략하지 말자 | 두 번째 줄이 `if` 와 상관없이 항상 실행 |
| 6 | `if (조건);` 세미콜론 금지 | 조건과 상관없이 블록이 항상 실행 |
| 7 | `switch` 의 `break` | 아래 `case` 까지 이어서 실행 (fall-through) |
| 8 | `switch` 는 값이 **같은지만** 비교 | `case x > 10:` 같은 조건식은 불가 |
| 9 | 새로운 `switch` (Java 14) | `break` 불필요, 끝에 `;` 필요, `default` 필요 |
| 10 | 삼항 연산자는 **값**만 넣는다 | 코드 블록 불가, 중첩하면 읽기 어려움 |

## 1. `if` 를 여러 개 쓸까, `else if` 로 묶을까?

### 1-1. 서로 연관된 조건 → `else if`

나이에 따라 미취학/초등학생/중학생/고등학생/성인 중 **하나만** 출력해야 하는 경우. (`If3` → `If4`)

```java
// If3 - if 를 각각 사용 (단점이 있음)
if (age <= 7) { System.out.println("미취학"); }
if (age >= 8 && age <= 13) { System.out.println("초등학생"); }
if (age >= 14 && age <= 16) { System.out.println("중학생"); }
if (age >= 17 && age <= 19) { System.out.println("고등학생"); }
if (age >= 20) { System.out.println("성인"); }
```

이 코드의 단점

- **불필요한 조건 검사**: 이미 조건을 만족해도 나머지 `if` 문의 조건을 모두 검사합니다. 나이가 5살이면 "미취학"이 출력된 뒤에도 아래 4개 조건을 모두 검사합니다.
- **코드 효율성 / 중복 체크**: `age <= 7` 이 거짓이면 이미 8살 이상인 것을 알 수 있습니다. 그런데 `age >= 8` 을 또 검사합니다.

```java
// If4 - else if 사용
if (age <= 7) {
    System.out.println("미취학");
} else if (age <= 13) {   // 이미 age > 7 이 보장됨
    System.out.println("초등학생");
} else if (age <= 16) {
    System.out.println("중학생");
} else if (age <= 19) {
    System.out.println("고등학생");
} else {
    System.out.println("성인");
}
```

`if ~ else if ~ else` 전체는 **하나의 묶음**입니다. 위에서부터 순서대로 맞는 조건을 찾고, 맞는 조건이 있으면 **딱 1개만 실행**하고 전체 `if` 문을 빠져나옵니다.

### 1-2. 서로 독립된 조건 → `if` 각각

여러 할인을 **동시에** 받을 수 있는 경우. (`If5` vs `If6`)

- 아이템 가격이 10000원 이상이면 1000원 할인
- 나이가 10살 이하면 1000원 할인

```java
// If5 - O 독립된 조건이므로 if 각각
if (price >= 10000) { discount = discount + 1000; }
if (age <= 10)      { discount = discount + 1000; }
// price = 10000, age = 10 → 총 할인 금액: 2000원
```

```java
// If6 - X else if 로 묶어 버림
if (price >= 10000) {
    discount = discount + 1000;
} else if (age <= 10) {
    discount = discount + 1000;
}
// price = 10000, age = 10 → 총 할인 금액: 1000원 (어린이 할인 누락!)
```

> 핵심: `if` 문에 조건이 여러 개 있다고 **항상 `if-else` 로 묶는 것이 아닙니다.**
> 조건이 서로 영향을 주지 않고 **각각 수행해야 하는 경우**에는 `if` 문을 분리해서 사용해야 합니다.

비슷한 예: 평점에 따른 영화 추천 (`MoveRateEx`) - 조건을 만족하는 영화를 **모두** 추천하므로 `if` 를 각각 사용합니다.

## 2. `else if` 는 조건 순서가 중요하다

`else if` 는 위에서부터 검사하고 **처음 맞는 것 하나만** 실행합니다. 그래서 넓은 조건이 위에 있으면 아래 조건은 절대 실행되지 않습니다.

```java
int score = 95;

// X 잘못된 순서
if (score >= 60) {
    System.out.println("D");   // 95점도 여기서 끝남!
} else if (score >= 70) {
    System.out.println("C");   // 절대 실행 안 됨
} else if (score >= 90) {
    System.out.println("A");   // 절대 실행 안 됨
}

// O 올바른 순서 (ScoreEx) - 좁은 조건(높은 점수)부터
if (score >= 90) {
    System.out.println("학점은 A입니다.");
} else if (score >= 80) {
    System.out.println("학점은 B입니다.");
} else if (score >= 70) {
    System.out.println("학점은 C입니다.");
} else if (score >= 60) {
    System.out.println("학점은 D입니다.");
} else {
    System.out.println("학점은 F입니다.");
}
```

> 큰 값 기준(`>=`)이면 **큰 값부터**, 작은 값 기준(`<=`)이면 **작은 값부터** 검사합니다. (`If4`, `DistanceEx` 는 `<=` 이므로 작은 값부터)

## 3. 경계값을 꼭 확인하자

`<` 와 `<=`, `>` 와 `>=` 를 헷갈리면 경계값에서 문제가 생깁니다.

```java
// "80점 이상 90점 미만: B"
if (score > 80 && score < 90)   // X 80점이 B에서 빠짐
if (score >= 80 && score < 90)  // O
```

```java
// 구간 사이에 빈틈이 생긴 경우
if (dollar < 0) {
    System.out.println("잘못된 금액입니다.");
} else if (dollar > 0) {
    System.out.println("환전 금액은 " + (dollar * 1300) + "원입니다.");
}
// dollar = 0 이면 아무것도 출력되지 않음! → 0인 경우를 따로 처리 (ExchangeRateEx)
```

> 테스트할 때는 **경계값**(80, 89, 90, 0, -1 등)을 넣어서 실행해 보세요. 강의 문제의 출력 예시도 경계값 위주로 되어 있습니다.

## 4. `{}` 중괄호 생략

`if` 문 다음에 실행할 명령이 **하나만** 있으면 `{}` 를 생략할 수 있습니다. (`else if`, `else` 도 마찬가지)

```java
if (true)
    System.out.println("if문에서 실행됨");
```

하지만 아래의 두 번째 문장은 **`if` 문과 무관**합니다. 들여쓰기는 의미가 없습니다.

```java
if (false)
    System.out.println("if문에서 실행됨");
    System.out.println("if문에서 실행 안됨"); // 조건과 상관없이 항상 실행됨!
```

둘 다 `if` 문 안에 포함하려면 `{}` 를 사용해야 합니다.

```java
if (true) {
    System.out.println("if문에서 실행됨");
    System.out.println("if문에서 실행 안됨");
}
```

일반적으로는 명령이 한 개만 있어도 **중괄호를 사용하는 것이 좋습니다.**

- **가독성**: 조건문의 범위가 명확하게 표시되어 코드의 흐름을 쉽게 이해할 수 있습니다.
- **유지보수성**: 나중에 코드를 추가할 때 오류를 덜 발생시킵니다. 중괄호가 없으면 추가한 코드가 `if` 문의 일부인지 명확하지 않습니다.

## 5. 자주 하는 문법 실수

### 5-1. `if (조건);` - 세미콜론

```java
int age = 10;
if (age >= 18); {                    // ; 때문에 if 문이 여기서 끝남
    System.out.println("성인입니다."); // 그냥 블록이라서 항상 실행됨!
}
```

컴파일 에러가 나지 않기 때문에 찾기 어렵습니다.

### 5-2. `=` 와 `==`

```java
int a = 5;
if (a = 5) { }     // X 컴파일 에러: int 는 boolean 이 아님 (자바는 다행히 막아 줌)

boolean flag = false;
if (flag = true) { } // 컴파일 됨! flag 에 true 를 대입 → 항상 실행
if (flag) { }        // O boolean 은 그냥 변수만 쓰는 것이 좋다
```

### 5-3. 문자열 비교는 `.equals()`

```java
String grade = "A";
if (grade == "A") { }       // X 성공할 때도, 실패할 때도 있음
if (grade.equals("A")) { }  // O
```

### 5-4. 범위 조건

```java
if (10 < a < 20) { }        // X 컴파일 에러
if (10 < a && a < 20) { }   // O
```

### 5-5. 조건문 안에서만 값을 넣은 변수

```java
int coupon;
if (grade == 1) {
    coupon = 1000;
} else if (grade == 2) {
    coupon = 2000;
}
System.out.println(coupon); // X 컴파일 에러: variable coupon might not have been initialized
```

`else` (또는 `switch` 의 `default`) 가 없으면 **값이 안 들어가는 경우**가 생기기 때문입니다. `Switch1`, `Switch2` 처럼 `else` / `default` 로 모든 경우에 값을 넣어 주세요. (자세한 내용은 `variable/변수_초기화.md`)

## 6. `switch` 문

```java
switch (조건식) {
    case value1:
        // 조건식의 결과 값이 value1일 때 실행되는 코드
        break;
    case value2:
        // 조건식의 결과 값이 value2일 때 실행되는 코드
        break;
    default:
        // 조건식의 결과 값이 위의 어떤 값에도 해당하지 않을 때 실행되는 코드
}
```

### 6-1. `break` 를 빠뜨리면 아래 `case` 까지 실행된다

`break` 문이 없으면, 일치하는 `case` **이후의 모든 `case` 코드들이 순서대로 실행**됩니다.

```java
// X break 를 실수로 빠뜨린 경우
int grade = 1;
switch (grade) {
    case 1:
        coupon = 1000;    // 실행
    case 2:
        coupon = 2000;    // 실행 (덮어씀)
    case 3:
        coupon = 3000;    // 실행 (덮어씀)
        break;
    default:
        coupon = 500;
}
// 1등급인데 쿠폰 3000!
```

이 성질을 **의도적으로** 쓰는 경우도 있습니다. (`Switch3` - 2등급도 3등급과 같이 3000원)

```java
switch (grade) {
    case 1:
        coupon = 1000;
        break;
    case 2:          // break 없음 → case 3 으로 이어짐
    case 3:
        coupon = 3000;
        break;
    default:
        coupon = 500;
        break;
}
```

> 권장: 의도적으로 `break` 를 생략할 때는 위처럼 **빈 `case` 를 붙여 쓰거나**, 주석으로 의도를 남겨 두세요. 실수인지 의도인지 다른 사람이 알 수 없습니다.

### 6-2. `switch` 는 값이 같은지만 비교할 수 있다

`switch` 문의 조건식에는 `x > 10` 같이 참/거짓 결과가 나오는 조건이 아니라, **단순히 값만** 넣을 수 있습니다.

```java
switch (score) {
    case score >= 90:  // X 컴파일 에러
}
```

| | `if` 문 | `switch` 문 |
|---|---|---|
| 비교 방식 | 참/거짓 조건식을 자유롭게 (`x > 10`, `x == 10`) | 값이 같은지만 (`==`) |
| 범위 조건 | 가능 | 불가 |
| 장점 | 모든 조건 표현 가능 | 특정 값에 따라 분기할 때 더 간결 |

`switch` 문 없이 `if` 문만 사용해도 됩니다. 하지만 특정 값에 따라 코드를 실행할 때는 `switch` 문을 사용하면 `if` 문보다 간결한 코드를 작성할 수 있습니다.

### 6-3. `switch` 에 쓸 수 있는 타입

- 가능: `int`, `char`, `byte`, `short`, **`String`** (`GradeSwitchEx`), `enum`
- 불가: `long`, `double`, `float`, `boolean`

```java
String grade = "B";
switch (grade) {
    case "A": ...
    case "B": ...   // 대소문자 구분! "b" 는 "B" 에 해당하지 않음
}
```

> 주의: `case` 값은 **중복될 수 없고**, 변수가 아니라 **상수**여야 합니다.
> 주의: `String` 변수가 `null` 이면 `switch` 에서 `NullPointerException` 이 발생합니다.

## 7. 자바 14 새로운 `switch` 문

```java
int coupon = switch (grade) {
    case 1 -> 1000;
    case 2 -> 2000;
    case 3 -> 3000;
    default -> 500;
};   // ← 세미콜론 필요!
```

기존 `switch` 문과 차이

- `->` 를 사용합니다.
- 선택된 데이터를 **반환**할 수 있습니다.
- `break` 가 필요 없습니다. (fall-through 가 없음)

주의할 점

```java
int coupon = switch (grade) {
    case 1 -> 1000;
    case 2, 3 -> 3000;   // 여러 값은 쉼표로 (Switch3 의 의도를 이렇게 표현)
    // default 없음 → X 컴파일 에러: 모든 경우를 처리하지 않음
};
```

- 값을 반환하는 `switch` 는 **모든 경우를 처리**해야 하므로 `default` 가 필요합니다.
- 식(expression)으로 쓰므로 끝에 **`;`** 를 붙여야 합니다.
- 기존 `case 1:` 문법과 새로운 `case 1 ->` 문법을 **한 `switch` 안에서 섞어 쓸 수 없습니다.**

## 8. 삼항 연산자 `? :`

```java
(조건) ? 참_표현식 : 거짓_표현식
```

```java
String status = (age >= 18) ? "성인" : "미성년자";   // CondOp2
int max = (a > b) ? a : b;                           // CondOpEx
String result = (x % 2 == 0) ? "짝수" : "홀수";        // EvenOddEx
```

- 항이 3개라서 삼항 연산자, 조건에 따라 결과가 나오므로 **조건 연산자**라고도 합니다.
- `if` 문처럼 **코드 블록을 넣을 수 없고 단순한 표현식(값)만** 넣을 수 있습니다.

```java
(age >= 18) ? System.out.println("성인") : System.out.println("미성년자"); // X 컴파일 에러
```

- 참/거짓 표현식의 **타입이 맞아야** 결과를 변수에 담을 수 있습니다.

```java
String s = (age >= 18) ? "성인" : 0;   // X 컴파일 에러: String 변수에 int 가 올 수 있음
```

- 중첩하면 읽기 매우 어려워집니다. 조건이 2개 이상이면 `if ~ else if` 를 사용하세요.

```java
String grade = (score >= 90) ? "A" : (score >= 80) ? "B" : (score >= 70) ? "C" : "F"; // 읽기 어려움
```

> 정리: **단순히 참과 거짓에 따라 특정 값을 구하는 경우**에만 삼항 연산자를 사용하자.

## 9. 정리 체크리스트

- [ ] 하나만 실행되어야 하면 `else if`, 각각 실행되어야 하면 `if` 를 따로
- [ ] `else if` 는 조건 순서 확인 (좁은 조건 먼저)
- [ ] 경계값(`<` vs `<=`)과 구간 사이 빈틈 확인
- [ ] 명령이 하나여도 `{}` 사용
- [ ] `if (조건);` 세미콜론 주의
- [ ] 문자열 비교는 `.equals()`
- [ ] `switch` 는 `break` 확인, 의도적 생략은 주석으로
- [ ] `switch` 는 값 비교만, 범위는 `if`
- [ ] 새로운 `switch` 는 `->`, `default`, 끝에 `;`
- [ ] 삼항 연산자는 단순한 값 선택에만, 중첩 금지
