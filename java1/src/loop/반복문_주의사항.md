## 1. 반복문 기본 구조

자바는 `while`, `do-while`, `for` 3가지 종류의 반복문을 제공합니다.

```java
// while: 조건식이 참이면 코드 블록 실행 → 다시 조건식 검사
while (조건식) {
    // 코드
}

// do-while: 코드 블록을 먼저 한 번 실행 → 조건식 검사
do {
    // 코드
} while (조건식);

// for: 1.초기식 → 2.조건식 → 3.코드 → 4.증감식 → 다시 2.조건식
for (1.초기식; 2.조건식; 4.증감식) {
    // 3.코드
}
```

> `for` 문의 **초기식은 딱 1번만** 실행됩니다. 실행 순서가 `초기식 → 조건식 → 코드 → 증감식 → 조건식 → ...` 인 것을 꼭 기억하세요. 증감식은 코드 **다음**에 실행됩니다.

## 2. 무한 루프

### 2-1. `while` 에서 증감을 빠뜨린 경우

`while` 은 조건식이 거짓이 될 때까지 계속 반복합니다. **조건을 바꾸는 코드**가 없으면 영원히 끝나지 않습니다.

```java
// X 무한 루프 - i 가 계속 1
int i = 1;
while (i <= 3) {
    System.out.println(i);
    // i++; 를 빠뜨림
}

// O While2_3
int sum = 0;
int i = 1;
int endNum = 3;
while (i <= endNum) {
    sum = sum + i;
    System.out.println("i=" + i + " sum=" + sum);
    i++;  // 조건을 바꾸는 코드
}
```

> 프로그램이 끝나지 않으면 IntelliJ 에서 빨간 정지 버튼(■)을 눌러 강제 종료하세요.

### 2-2. `continue` 앞에서 증감을 빠뜨린 경우

`continue` 를 만나면 **아래 코드를 건너뛰고 바로 조건식으로** 이동합니다. 증감 코드가 `continue` 아래에 있으면 증감도 같이 건너뜁니다.

```java
// X 무한 루프 - i 가 3에서 멈춤
int i = 1;
while (i <= 5) {
    if (i == 3) {
        continue;          // i++ 를 건너뜀 → i 는 영원히 3
    }
    System.out.println(i);
    i++;
}

// O Continue1 - continue 전에 i++
int i = 1;
while (i <= 5) {
    if (i == 3) {
        i++;
        continue;
    }
    System.out.println(i);
    i++;
}
// 출력: 1 2 4 5
```

> `for` 문에서는 이 문제가 없습니다. `continue` 를 만나면 **증감식으로 이동**한 다음 조건식을 검사하기 때문입니다.
> ```java
> for (int i = 1; i <= 5; i++) {
>     if (i == 3) {
>         continue;  // i++ 는 증감식에서 자동으로 실행됨
>     }
>     System.out.println(i);
> }
> ```

### 2-3. 의도적인 무한 루프 `while (true)` / `for (;;)`

조건이 항상 참이므로 무한 반복합니다. **반드시 `break` 로 빠져나올 방법**이 있어야 합니다. (`Break1`, `Break2`)

```java
int sum = 0;
int i = 1;
while (true) {
    sum += i;
    if (sum > 10) {
        System.out.println("합이 10보다 크면 종료: i=" + i + " sum=" + sum);
        break;  // 없으면 영원히 반복
    }
    i++;
}
// 합이 10보다 크면 종료: i=5 sum=15
```

`for` 문의 초기식, 조건식, 증감식은 모두 생략할 수 있습니다. 단, 생략해도 **세미콜론(`;`)은 유지**해야 합니다.

```java
for (;;) { }        // while (true) 와 같음
for (int i = 1; ; i++) { }  // 조건식만 생략 (Break3)
```

## 3. 반복 횟수 실수 (off-by-one)

반복문에서 가장 흔한 버그는 **한 번 더, 또는 한 번 덜** 반복하는 것입니다.

```java
for (int i = 1; i <= 10; i++)  // 1 ~ 10  → 10번
for (int i = 1; i < 10; i++)   // 1 ~ 9   → 9번 (10 누락!)
for (int i = 0; i < 10; i++)   // 0 ~ 9   → 10번
for (int i = 0; i <= 10; i++)  // 0 ~ 10  → 11번
```

| 시작 | 조건 | 반복 횟수 | 주로 쓰는 곳 |
|---|---|---|---|
| `i = 1` | `i <= n` | n번 | 1부터 n까지 셀 때 (`ForEx1`, `ForEx3`) |
| `i = 0` | `i < n` | n번 | 횟수만 중요할 때, 나중에 배울 배열 (`Nested1`) |

> 헷갈리면 반복 횟수가 작은 값(예: `endNum = 3`)으로 바꿔서 **손으로 따라가 보세요.** 강의의 `While2_3` 분석처럼 `i` 와 `sum` 의 값을 루프마다 적어 보면 됩니다.
> ```
> //루프 1: while (i(1) <= endNum(3)) -> true,  sum(1), i(2)
> //루프 2: while (i(2) <= endNum(3)) -> true,  sum(3), i(3)
> //루프 3: while (i(3) <= endNum(3)) -> true,  sum(6), i(4)
> //루프 4: while (i(4) <= endNum(3)) -> false → 종료
> ```

## 4. 세미콜론(`;`) 실수

### 4-1. `while (조건);`

```java
int i = 1;
while (i <= 3); {        // ; 때문에 while 의 본문이 "빈 문장"이 됨
    System.out.println(i);
    i++;
}
// i 가 바뀌지 않으므로 무한 루프! (아무것도 출력되지 않고 멈춤)
```

### 4-2. `for (...);`

```java
for (int i = 1; i <= 3; i++); {   // 빈 문장을 3번 반복
    System.out.println("Hello");  // 그냥 블록 → 1번만 실행
}
```

컴파일 에러가 나지 않기 때문에 찾기 어렵습니다.

### 4-3. `do-while` 은 끝에 `;` 가 **필요**

```java
do {
    System.out.println(i);
    i++;
} while (i < 3);   // ← 여기는 ; 가 있어야 함 (없으면 컴파일 에러)
```

## 5. `do-while` 은 최소 한 번 실행된다

`do-while` 문은 `while` 문과 비슷하지만, **조건에 상관없이 무조건 한 번은 코드를 실행**합니다.

```java
// DoWhile1 - while
int i = 10;
while (i < 3) {
    System.out.println("현재 숫자는:" + i);
    i++;
}
// 출력 없음 (처음부터 조건이 거짓)

// DoWhile2 - do-while
int i = 10;
do {
    System.out.println("현재 숫자는:" + i);
    i++;
} while (i < 3);
// 현재 숫자는:10  (조건이 거짓이어도 한 번 실행)
```

> `do-while` 은 **최초 한 번은 코드 블록을 꼭 실행해야 하는 경우**에만 사용하세요. 그렇지 않으면 의도와 다르게 한 번 실행될 수 있습니다.

## 6. `break` 와 `continue`

| 키워드 | 동작 |
|---|---|
| `break` | 반복문을 **즉시 종료**하고 빠져나감 |
| `continue` | 반복문의 나머지 부분을 건너뛰고 **다음 반복**으로 진행 (`while` → 조건식, `for` → 증감식) |

```java
while (조건식) {
    코드1;
    break;    // 즉시 while문 종료로 이동한다.
    코드2;    // 실행 안 됨
}

while (조건식) {
    코드1;
    continue; // 즉시 조건식으로 이동한다.
    코드2;    // 실행 안 됨
}
```

### 6-1. 중첩 반복문에서는 **가장 가까운** 반복문만 빠져나간다

```java
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) {
            break;       // 안쪽 for 만 종료, 바깥 for 는 계속
        }
        System.out.println(i + "-" + j);
    }
}
// 0-0
// 1-0
// 2-0
```

> 바깥 반복문까지 한 번에 빠져나가려면 **라벨(label)** 을 사용할 수 있습니다. 하지만 코드가 복잡해지므로 자주 쓰지는 않습니다.
> ```java
> outer:
> for (int i = 0; i < 3; i++) {
>     for (int j = 0; j < 3; j++) {
>         if (j == 1) break outer;  // 바깥 for 까지 종료
>     }
> }
> ```

### 6-2. 반복문 안의 `switch` 에서 `break`

반복문 안에 `switch` 가 있으면, `switch` 의 `break` 는 **`switch` 만 빠져나갑니다.** 반복문은 계속 돕니다.

```java
while (true) {
    switch (menu) {
        case 0:
            break;   // switch 만 종료! while 은 계속 → 무한 루프
    }
}
```

## 7. 변수 선언 위치

### 7-1. 누적 변수는 반복문 **밖**에서 선언

```java
// X 매번 sum 이 0 으로 초기화됨
for (int i = 1; i <= 3; i++) {
    int sum = 0;
    sum += i;
}
// 게다가 반복문 밖에서는 sum 을 사용할 수도 없음

// O ForEx3
int sum = 0;
for (int i = 1; i <= max; i++) {
    sum += i;
}
System.out.println(sum);
```

### 7-2. `for` 의 변수는 반복문 밖에서 사용할 수 없다

`for` 문의 초기식에서 선언한 변수는 **`for` 블록 안에서만** 사용할 수 있습니다.

```java
for (int i = 1; i <= 10; i++) { }
System.out.println(i);   // X 컴파일 에러: cannot find symbol

int j = 1;
while (j <= 10) { j++; }
System.out.println(j);   // O 11 - while 은 밖에서 선언했으므로 사용 가능
```

> 반복이 끝난 뒤의 값이 필요하면 `while` 처럼 **반복문 밖에서 선언**하세요. 자세한 내용은 `6. 스코프, 형변환`에서 다룹니다.

### 7-3. `for` 문 안에서 카운터 변수를 직접 바꾸지 말 것

```java
for (int i = 1; i <= 10; i++) {
    i += 2;   // X 증감식과 본문 두 곳에서 i 가 바뀜 → 흐름을 알기 어려움
}
```

카운터 변수는 **증감식에서만** 바꾸는 것이 `for` 문을 쓰는 이유입니다. 반복 중에 조건이 바뀌어야 한다면 `while` 문을 사용하세요.

### 7-4. `for` 초기식에 여러 변수 선언

쉼표(`,`)로 여러 변수를 선언할 수 있습니다. 단, **같은 타입**이어야 합니다. (`ForEx2`)

```java
for (int num = 2, count = 1; count <= 10; num += 2, count++) {
    System.out.println(num);
}

for (int a = 0, double b = 0.0; ...)  // X 컴파일 에러: 다른 타입은 불가
```

## 8. 중첩 반복문

반복문은 내부에 또 반복문을 만들 수 있습니다. `for`, `while` 모두 가능합니다.

```java
// Nested1
for (int i = 0; i < 2; i++) {
    System.out.println("외부 for 시작 i:" + i);
    for (int j = 0; j < 3; j++) {
        System.out.println("-> 내부 for " + i + "-" + j);
    }
    System.out.println("외부 for 종료 i:" + i);
}
```

- 외부 for 1번당 내부 for 가 3번 실행 → 외부(2) × 내부(3) = **총 6번** 내부 코드 실행
- 반복 횟수가 곱해지므로, 중첩이 깊어질수록 실행 횟수가 급격히 늘어납니다.

### 8-1. `i` 와 `j` 를 헷갈리는 실수

```java
// X 내부 for 에서 i++ → 내부 for 가 끝나지 않음 (무한 루프)
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= 9; i++) { }
}

// X 내부 for 에서 같은 이름 i 를 다시 선언 → 컴파일 에러
for (int i = 1; i <= 9; i++) {
    for (int i = 1; i <= 9; i++) { }
}
```

### 8-2. 내부 반복 횟수가 외부 변수에 따라 달라지는 경우 (`NestedEx2`)

```java
int rows = 5;
for (int i = 1; i <= rows; i++) {
    for (int j = 1; j <= i; j++) {    // j <= i : i 번째 줄에 별 i 개
        System.out.print("*");
    }
    System.out.println();             // 한 줄이 끝나면 줄바꿈
}
```

> `print()` 는 줄바꿈을 하지 않고, `println()` 은 출력 후 다음 라인으로 넘어갑니다. **줄바꿈 위치**(내부 for 안 / 밖)를 잘못 넣으면 모양이 깨집니다.

## 9. `for` vs `while` 선택하기

| | `for` 문 | `while` 문 |
|---|---|---|
| 장점 | 초기화, 조건 체크, 반복 후 작업을 **한 줄**에서 처리 | 루프 내부에서 조건이 변경되는 경우 관리하기 쉬움 |
| | 정해진 횟수만큼 반복할 때 적합 | 더 복잡한 조건과 시나리오에 적합 |
| | 루프 변수의 범위가 for 블록으로 제한 → 실수로 변경할 가능성이 적음 | 종료 시점을 명확하게 알 수 없을 때 유용 |
| 단점 | 루프 내부에서 조건이 바뀌면 관리하기 어려움 | 초기화, 조건 체크, 반복 후 작업이 **분산**되어 이해하기 어려울 수 있음 |
| | 복잡한 조건에는 `while` 이 더 적합할 수 있음 | 루프 변수가 while 블록 밖에서도 접근 가능 → 실수로 변경할 수 있음 |

> 한줄 정리: **정해진 횟수만큼 반복하면 `for`, 그렇지 않으면 `while`.** 물론 이것이 항상 정답은 아니니 기준으로 삼는 정도로 이해하자.

## 10. 그 외 주의할 점

### 10-1. 누적 합의 오버플로우

`int` 는 약 20억까지만 표현할 수 있습니다. 반복해서 더하다 보면 범위를 넘어 **음수**가 될 수 있습니다. 에러가 나지 않으므로 주의하세요.

```java
int sum = 0;
for (int i = 1; i <= 100000; i++) {
    sum += i;
}
System.out.println(sum);  // 705082704 (정답 5000050000 이 아님!)

long sum2 = 0;            // O 큰 값이면 long
```

### 10-2. 실수(`double`)를 카운터로 쓰지 말 것

실수는 정확한 값을 표현하지 못해서 반복 횟수가 예상과 달라질 수 있습니다.

```java
for (double d = 0.0; d != 1.0; d += 0.1) { }  // X 0.1 을 10번 더해도 정확히 1.0 이 아님 → 무한 루프
for (int i = 0; i < 10; i++) { double d = i * 0.1; }  // O 카운터는 정수로
```
